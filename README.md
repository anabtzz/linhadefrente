# Linha de Frente

Site institucional da Linha de Frente, feito com HTML, CSS e JavaScript sem framework.

## Uso

O site usa apenas HTML, CSS e JavaScript, sem framework, dependências ou etapa de build. Abra `index.html` diretamente no navegador.

Para publicar, envie `index.html`, a pasta `src/` e a pasta `public/` para o mesmo diretório no serviço de hospedagem.

## Netlify

O arquivo `netlify.toml` já configura a publicação da raiz do projeto. Conecte o repositório ao Netlify e deixe o comando de build vazio; não é necessário instalar dependências.
